# Architecture

The CLI and GUI share a Python core. The corpus is a read-only source; SQLite and extraction caches live in a separate workspace. Catalogs include monster and map names from CQ Tool, without invented coordinates.

Current shared-provider flow: prompt + catalog -> structured intent -> local search of parsed corpus records -> hash-checked references -> structured QuestPlan proposal -> local schema/provenance validation -> JSON requiring review. A provider interface exposes structured requests: Codex runs the official CLI with personal account login; Gemini and OpenAI use their documented APIs. Codex is the primary choice. Each plan uses two model turns and never executes proposed BIN/database changes. An offline `draft` command also preserves prompts and filtered context without model calls. Codex account integration has a successful live two-stage test; Gemini has offline tests and still needs live-key verification.

Current build flow: reviewed QuestPlan -> model-produced typed BuildSpec bound to a selected base/target ID -> deterministic conservative BIN patch engine -> read-back and opaque-byte validation -> new workspace export. `unresolved` or actual unsupported edits block building; nonblocking runtime caveats remain warnings. Full binary graph reconstruction is future work. The model cannot supply binary offsets or execute a patch. The writer edits supported metadata and appends replacement string, hash-bound spawn and selected reward packages while preserving the native map package. Additional evidence requests are executed by typed read-only host research; invalid plans/edits receive bounded validation feedback. Each field must retain its source, revision and evidence level. Selecting a map means preserving its native package, including zones and transitions, rather than changing only the map ID.

Laboratory rules are portable domain knowledge; personal history, credentials, proprietary quests and machine-specific paths do not belong in the repository. Development is independent of the old editor.
